# Estudio: POO, patrones de diseño y MVC

Página web estática (un solo archivo, sin dependencias ni build) que explica, para cada tema:
introducción, aterrizaje a programación, esquema visual y ejemplo en código.

Temas: Objeto, Abstracción, Herencia, Patrones de diseño, MVC, Abstract Factory y Builder,
más un cuadro comparativo Abstract Factory vs Builder.

## Ver la página

Abre `index.html` en el navegador, o publícala con GitHub Pages
(Settings > Pages > Deploy from a branch > `main` / root).

## Notas

- Solo carga las fuentes desde Google Fonts; si no hay conexión usa fuentes del sistema.
- Los esquemas e iconos son SVG en línea.
